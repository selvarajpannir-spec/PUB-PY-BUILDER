Excel + Word Template → Bulk Documents

1 How your Excel sheet should look

Put column headers in the first row. Each following row becomes one generated document.

NAME EMP_ID DEPARTMENT SALARY
Rahul Sharma E1024 Sales 45000
Priya Patel E1025 HR 52000
Amit Kumar E1026 IT 61000

Supported format: .xlsx (First sheet is used automatically)

2 How your Word template should look

Create a normal .docx file and insert placeholders using double curly braces that match your Excel column names:

{{NAME}} {{EMP_ID}} {{DEPARTMENT}} {{SALARY}}
Sample Word content:

Date: {{DATE}}

Dear {{NAME}},

Employee ID: {{EMP_ID}}
Department: {{DEPARTMENT}}
Monthly Salary: ₹{{SALARY}}

This letter confirms your employment details.

Regards,
HR Department

The app replaces every {{COLUMN}} with the matching value from each Excel row.

3 What output you will get

After generation you receive one combined Word document containing one page (or section) for every row in your Excel file.

✓ File saved to Downloads folder
✓ Named like generated_1723….docx
✓ You can open it in Microsoft Word, Google Docs, or WPS
✓ Then use Print → Save as PDF if you need a PDF
