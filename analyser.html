How to use
  1. Folder defaults to phone Download (or choose another if offered).
  2. Tap Scan. Up to 50 new files are analysed this run.
  3. Files already listed by name are skipped.
  4. Rows appear one by one as each file finishes.
  5. Table has no size limit — it grows until you delete.
  6. Use checkboxes to delete records; optionally delete the file on storage.
